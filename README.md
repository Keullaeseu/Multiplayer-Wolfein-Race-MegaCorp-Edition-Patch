# Multiplayer Wolfein Race MegaCorp Edition Patch

A RimWorld Multiplayer compatibility patch for [Wolfein Race MegaCorp Edition](https://steamcommunity.com/sharedfiles/filedetails/?id=3687841204).

This mod is designed to improve multiplayer synchronization when playing with the [Wolfein Race MegaCorp Edition](https://steamcommunity.com/sharedfiles/filedetails/?id=3687841204) mod and RimWorld Multiplayer.

## Features

- Adds multiplayer compatibility for [Wolfein Race MegaCorp Edition](https://steamcommunity.com/sharedfiles/filedetails/?id=3687841204), including:
  - Switch-mode ranged weapon gizmo and verb rebuild.
  - Faction comms dialog (donations, military aid calls, prototype heart purchase, data-quest option).
  - Civilian ship crash and debt slave choice letters.
  - Armistice Day caravan visit and pawn join dialog.
  - Black market trade ship incident RNG isolation.
  - Dragon breath visual-effect RNG isolation.

## Requirements

- RimWorld
- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- RimWorld Multiplayer
  - [GitHub version](https://github.com/rwmt/Multiplayer) or [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745) version
- [Wolfein Race MegaCorp Edition](https://steamcommunity.com/sharedfiles/filedetails/?id=3687841204)
- [Wolfein Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3473140562) (MegaCorp Edition dependency)
- [Multiplayer Wolfein Race Patch](https://github.com/Keullaeseu/Multiplayer-Wolfein-Race-Patch/releases/latest)
  — required: covers the base Wolfein systems MegaCorp builds on (rest pod, artificial moon toggle, energy shield recharge, tool switching, turret gizmos, float menus, sprint jump order, incidents, map-gen seeds).
- [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276) (Wolfein Race dependency)
- [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)
  — required: covers the Ancot Library base systems Wolfein builds on (jump-verb chain, container, mortar and injector jobs).
- [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762) (Wolfein Race dependency)
- [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)
  — required: covers the styling station and alien-comp appearance sync for HAR races including Wolfein.

The host and every connected player must use compatible versions of all required mods.

## Installation

### Steam Workshop

Subscribe to the required mods and add them to your RimWorld mod list in the following order:

1. Harmony
2. Core
3. Royalty, Ideology, Biotech, and Anomaly, if applicable
4. RimWorld Multiplayer
5. [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276)
6. [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)
7. [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762)
8. [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)
9. [Wolfein Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3473140562)
10. [Multiplayer Wolfein Race Patch](https://github.com/Keullaeseu/Multiplayer-Wolfein-Race-Patch/releases/latest)
11. [Wolfein Race MegaCorp Edition](https://steamcommunity.com/sharedfiles/filedetails/?id=3687841204)
12. [Multiplayer Wolfein Race MegaCorp Edition Patch](https://github.com/Keullaeseu/Multiplayer-Wolfein-Race-MegaCorp-Edition-Patch/releases/latest)

The patch should load after RimWorld Multiplayer, [Wolfein Race MegaCorp Edition](https://steamcommunity.com/sharedfiles/filedetails/?id=3687841204), and all companion patches listed above.

### Manual Installation

1. Download the latest release from the [**Releases**](https://github.com/Keullaeseu/Multiplayer-Wolfein-Race-MegaCorp-Edition-Patch/releases/latest) section.
2. Extract the mod folder into your RimWorld `Mods` directory.
3. Enable the required mods in RimWorld.
4. Use the recommended load order listed above.
5. Make sure every multiplayer player has the same mod list, configuration, and load order.

## Multiplayer Usage

All players should have the following mods installed and enabled:

- RimWorld Multiplayer
- [Wolfein Race MegaCorp Edition](https://steamcommunity.com/sharedfiles/filedetails/?id=3687841204)
- [Multiplayer Wolfein Race MegaCorp Edition Patch](https://github.com/Keullaeseu/Multiplayer-Wolfein-Race-MegaCorp-Edition-Patch/releases/latest)
- [Wolfein Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3473140562)
- [Multiplayer Wolfein Race Patch](https://github.com/Keullaeseu/Multiplayer-Wolfein-Race-Patch/releases/latest)
- [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276)
- [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)
- [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762)
- [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)
- All other required Wolfein Race MegaCorp Edition dependencies

The host and all connected clients should use the same:

- RimWorld version
- RimWorld Multiplayer version
- Wolfein Race MegaCorp Edition version
- Multiplayer Wolfein Race MegaCorp Edition Patch version
- Multiplayer Wolfein Race Patch version
- Multiplayer Ancot Library Patch version
- Multiplayer Humanoid Alien Races Patch version
- Mod configuration (including Wolfein Race MegaCorp Edition mod settings — values feed quest rewards, aid costs, loot, and RNG scaling)
- Mod load order

Do not add, remove, update, or reorder mods while players are connected to the same multiplayer session.

## Compatibility

This patch is intended to provide multiplayer compatibility for [Wolfein Race MegaCorp Edition](https://steamcommunity.com/sharedfiles/filedetails/?id=3687841204)
itself (weapon-mode switching, faction comms dialog, choice letters, Armistice Day
caravan visit, black market incident, dragon breath effects).
Base Wolfein systems, Ancot Library base systems, and Humanoid Alien Races styling
are covered by the required companion patches listed above, not duplicated here.

It does not replace:

- [RimWorld Multiplayer](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745)
- [Wolfein Race MegaCorp Edition](https://steamcommunity.com/sharedfiles/filedetails/?id=3687841204)

## Known Limitations

- Compatibility may be affected by future RimWorld updates.
- Compatibility may be affected by future updates to RimWorld Multiplayer, Wolfein Race, or Wolfein Race MegaCorp Edition.
- All players must use identical Wolfein Race MegaCorp Edition mod settings; differing multipliers change quest rewards, aid costs, loot, and RNG scaling, which can desync the session.
